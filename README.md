# forerunner-sandbox (kite club)

A throwaway repository for testing how Forerunner works with a real GitHub repository: branches,
pull requests and their links. Forerunner's agents may push branches and open pull requests here.

## Hello page

`index.html` is a small static page that greets visitors.
It has no scripts or external resources.
Open it directly in a browser, for example by double-clicking the file.
