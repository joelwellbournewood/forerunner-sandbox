# 0001: Plain static HTML

Decision: Build the page as plain hand-written HTML files in the existing kite/ folder, with no framework or build step, and do the work as three chained coder tasks.

Why: the brief asks for a small page, three dependent edits and nothing else. Plain HTML opens locally and needs no hosting or tooling choice.

The brief names only the third trip, "Lake day". The first task's coder picks two simple trip names; they are ordinary list items and easy to rename later.

The tasks run in order because each edits the file the previous one produced: create the page, add the third trip, then link it from kite/index.html.
